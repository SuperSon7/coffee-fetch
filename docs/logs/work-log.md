# Coffee Fetch — 작업 시작·종료 기록

목적: 제품을 만드는 전 과정을 경험하고, AI와 일할 때의 병목을 측정해 내 작업 방식을 개선한다. 기록 자체는 시작 3분·종료 5분 이내를 목표로 한다.

## 사용하는 방법

1. 시작할 때 아래 양식을 복사해 맨 위에 새 세션을 추가한다. 날짜·시간은 실제 작업 환경의 Asia/Seoul 기준으로 적는다.
2. 오늘 집중할 이슈는 1개를 기본으로 한다. 예상 시간은 성과 평가가 아니라 계획과 실제 차이를 배우기 위한 값이다.
3. 종료할 때 완료·미완료를 구분하고 결과물/커밋/이슈 링크를 붙인다. 실제 시간을 모르면 `미측정`으로 남긴다. AI가 시간을 추정해 채우지 않는다.
4. 작업 시간은 휴식 제외 경과 시간이다. 직접 작업·검토 / AI·도구 대기 / 외부 차단을 겹치지 않게 나눈다. 재작업 시간은 직접 작업 시간의 일부로 별도 표시하며 총합에 다시 더하지 않는다. 대기 중 다른 일을 했다면 직접 작업으로 센다.
5. 막힘은 관찰과 원인 가설을 구분한다. 학습에 쓴 시간이 모두 낭비는 아니다.
6. 세션 5개 또는 주 1회 회고한다. 다음 세션에서 바꿀 것은 하나만 골라 비슷한 작업에서 비교한다.

공개 저장소의 기록에는 비밀키, 업무 내부 자료, 개인 정보를 넣지 않는다. 이슈 상태는 GitHub에서, 작업 과정과 시간은 이 문서에서 관리한다.
