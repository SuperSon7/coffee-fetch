## 이번 논의의 설계 가설

- 목적: 관심 기술을 모두 따라가기보다 업무에 적용할 아이디어를 발견하고 남기는 습관.
- 관심 프로필: 도구 목록에 현재 고민하는 문제 1~3개를 추가.
- 아침: 제한된 카드에서 살펴볼 자료 선택. 저녁: 사용자가 표시한 읽음·메모를 정리. 주간: 써볼 아이디어 1개 재검토.
- 발표는 초록으로 먼저 선별하고 필요할 때 자막·슬라이드를 확보. 자막이나 슬라이드 근거 없이 영상 구간·발표 결론을 생성하지 않음.
- 수집·주기 실행·읽기 기록은 일반 프로그램으로 처리. AI는 선별된 텍스트의 요약·분류·메모 정리에 사용.
- 로컬 모델은 실제 자료로 평가 후 선정. 야간 처리로 지연 허용 범위를 늘리되 하드웨어·입력 길이·번역 정확성은 따로 확인.
- 첫 실험: 기사·릴리스 노트·발표 초록·자막 발췌를 합쳐 20건 정도로 사실성, 버전·숫자 보존, 원문에 없는 주장, 처리 시간과 메모리를 비교.

위 항목은 당시의 설계 제안이다. 현재 채택 여부는 [제품 정의](../product/definition.md)를 따른다.
