# Coffee Fetch 디자인 기준

2026-11-18 · 제품 동작은 [제품 정의](definition.md), 시각 기준은 이 문서와 [목업](mockup/index.html)에서 관리합니다.

## 방향

Feedly처럼 빠르게 훑는 기술 소식 목록에 절제된 Liquid Glass 느낌을 더합니다. 브리핑은 읽기(Read), 설정은 작업(Operate) 중심입니다. 큰 장식이나 카드 테두리보다 제목·요약·출처의 위계가 먼저 보이게 합니다.

- PC: 왼쪽 메뉴와 관심 기술 목록, 오른쪽 읽기 영역. 개별 카드는 얇은 구분선으로 나눕니다.
- 모바일: 위쪽 브랜드, 아래 고정 메뉴. 본문과 메뉴가 겹치지 않도록 하단 여백을 둡니다.
- 유리 소재: 탐색 메뉴와 날짜·회차 조작부에만 사용합니다. 소식 본문은 불투명한 배경을 유지합니다. 웹의 반투명·블러 표현이며 Apple의 네이티브 광학 효과를 그대로 구현한 것은 아닙니다.
- 정보 순서: 기술·유형·우선 확인 → 제목 → 요약 → 출처·날짜·회차 → 원문·읽음·북마크·관련 카드.
- 기능: 유형 필터, 과거 회차, 카드별 읽음·북마크, 소식별 읽기 집계를 유지합니다. 예시 자료는 가상임을 표시합니다.

## 반복 사용할 값

| 요소 | 기준 |
|---|---|
| 본문 배경 / 글자 | `#fcfcfa` / `#202c26` |
| 보조 글자 / 구분선 | `#56645c` / `#e0e6df` |
| 강조 / 선택 배경 | `#246247` / `#e4eee6` |
| 우선 확인 | 옅은 황토색 배경과 텍스트. 색만으로 의미를 전달하지 않음 |
| 글꼴 | 시스템 sans-serif, 한국어는 맑은 고딕 등 시스템 대체 글꼴. 외부 폰트 다운로드 없음 |
| 크기 | PC 화면 제목 30px, 소식 제목 17px, 요약 13px, 보조 정보 11–12px |
| 목록 간격 | 소식 상하 20px, 제목과 요약은 가까이 배치 |
| 화면 폭 | 최대 1200px, PC 사이드바 196px, 600px 이하 하단 메뉴 |

## 조작과 접근성

| 조작 | 적용 |
|---|---|
| 유형 필터·화면 전환 | 반복 사용하므로 애니메이션 없이 즉시 전환. 선택 상태와 키보드 포커스 표시 |
| 읽음·북마크 | 명시적 버튼과 상태 텍스트, 처리 결과 알림 |
| 모바일 메뉴·주요 카드 동작 | 44px 이상 터치 영역, 하단 안전 영역 고려 |
| 투명 효과 | 지원되지 않거나 투명도 감소 설정이면 불투명 배경 |
| 설정 | 입력에 레이블, 저장 버튼은 흰 글자와 녹색 배경 |

## 검증과 범위

Windows Edge에서 PC·모바일 캡처를 확인했습니다. 320·360·768·1100px에서 주요 화면 가로 넘침, 360px 하단 메뉴 위치, 기존 필터·회차·읽음·북마크·재생성 동작 검사를 통과했습니다. 실제 iOS Safari와 실기기 사용성은 아직 검증하지 않았습니다. 현재 결과물은 목업이며 수집·서버·영속 저장 구현은 포함하지 않습니다.
