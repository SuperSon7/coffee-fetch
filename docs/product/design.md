# Coffee Fetch 디자인 기준

## 채택한 디자인 — Coffee Blend

2026-11-20: 사용자가 초록색을 제외하고 ‘블렌딩 커피 같은 고급스러운 느낌’을 요청했습니다. 이후 사용자가 이 방향으로 구현 진행을 요청하여 채택했습니다. 이전안은 비교를 위해 유지합니다.

### 디자인 의도

- **장면:** 아침에 개인 기술 브리핑을 읽는 화면. 본문은 밝게 두고 짙은 커피색 메뉴가 주변을 잡습니다.
- **구성:** 에스프레소 사이드바, 아이보리 읽기 영역, 버건디 선택 상태. 얇은 황동색 구분선은 헤더에만 사용합니다.
- **타이포:** Coffee Fetch 로고와 The Daily Blend 표제에 Libre Caslon Display. 한국어 본문과 버튼은 시스템 sans-serif를 사용합니다. 브랜드 표현과 반복 읽기의 역할을 분리합니다.
- **첫 화면:** 왼쪽 로고·메뉴·관심 기술, 오른쪽 표제·회차·유형 필터·소식 목록. 모바일에서는 작은 브랜드 헤더와 하단 메뉴로 전환합니다.
- **소재 표현:** 무광 종이와 원두 패키지의 색 대비. 본문에 사진·질감·블러를 깔지 않습니다. 투명 효과는 모바일 하단 메뉴에만 남깁니다.
- **유지:** 카드별 읽음·북마크, 소식별 집계, 회차 선택, 필터, 설정 동작. 가상 자료 표시와 원문 출처를 유지합니다.
- **검토할 점:** 이전안보다 짙은 사이드바와 세리프 로고의 존재감이 강합니다. 브랜드 분위기와 일상적인 읽기 도구 사이의 균형은 실제 사용 중 조정합니다.

레퍼런스 사진은 조사·시각 검토용이며 목업이나 공개 저장소에 복제하지 않았습니다. PNG는 이 프로젝트의 HTML을 Edge에서 렌더링한 캡처입니다.

### 조작 검토와 검증

| Before | After | Why |
|---|---|---|
| 녹색 선택·포커스 | 버건디 선택·본문 포커스, 어두운 메뉴의 밝은 포커스 | 배경마다 식별 가능한 상태 유지 |
| 반복 필터 전환에 애니메이션 없음 | 그대로 즉시 전환 | 매일 읽는 흐름에 불필요한 지연을 추가하지 않음 |
| 보조 정보 10–11px | 주요 메타데이터·동작 12px, 보조 표기 11px | 작은 글자 가독성 보완 |

기존 캡처 도구에 선택적 대상 폴더 인자와 서체 로딩 대기를 추가했습니다. 기본 대상은 이전 목업 그대로입니다.

- Edge에서 브리핑·설정·모바일 캡처 시각 확인, 320·360·768·1100px 주요 화면 넘침 및 모바일 하단 메뉴 위치 검사 통과.
- 필터·빈 결과·회차·개별 읽음·소식 집계·북마크·재생성 기존 검사 통과.
- 스킬 정적 검사: 작은 글자 권고를 반영. 크림색 배경 경고는 요청한 커피 분위기와 직접 확인한 레퍼런스에 따른 의도적 선택으로 유지.
- 한계: 실제 iOS Safari, 키보드·스크린리더 전체 사용성 검증은 미실시. 데이터 수집·서버·실제 원문 연결은 기존처럼 구현하지 않은 목업입니다.

## 이전안 — Feedly + 녹색 Liquid Glass

아래는 2026-11-18 버전의 비교용 기록입니다. 현재 구현 기준은 위 Coffee Blend입니다.

2026-11-18 · 제품 동작은 [제품 정의](definition.md), 시각 기준은 이 문서와 [목업](mockup/index.html)에서 관리합니다.

## 방향

Feedly처럼 빠르게 훑는 기술 소식 목록에 절제된 Liquid Glass 느낌을 더합니다. 브리핑은 읽기(Read), 설정은 작업(Operate) 중심입니다. 큰 장식이나 카드 테두리보다 제목·요약·출처의 위계가 먼저 보이게 합니다.

- PC: 왼쪽 메뉴와 관심 기술 목록, 오른쪽 읽기 영역. 개별 카드는 얇은 구분선으로 나눕니다.
- 모바일: 위쪽 브랜드, 아래 고정 메뉴. 본문과 메뉴가 겹치지 않도록 하단 여백을 둡니다.
- 유리 소재: 탐색 메뉴와 날짜·회차 조작부에만 사용합니다. 소식 본문은 불투명한 배경을 유지합니다. 웹의 반투명·블러 표현이며 Apple의 네이티브 광학 효과를 그대로 구현한 것은 아닙니다.
- 정보 순서: 기술·유형·우선 확인 → 제목 → 요약 → 출처·날짜·회차 → 원문·읽음·북마크·관련 카드.
- 기능: 유형 필터, 과거 회차, 카드별 읽음·북마크, 소식별 읽기 집계를 유지합니다. 예시 자료는 가상임을 표시합니다.

## 반복 사용할 값

| 요소 | 기준 |
|---|---|
| 본문 배경 / 글자 | `#fcfcfa` / `#202c26` |
| 보조 글자 / 구분선 | `#56645c` / `#e0e6df` |
| 강조 / 선택 배경 | `#246247` / `#e4eee6` |
| 우선 확인 | 옅은 황토색 배경과 텍스트. 색만으로 의미를 전달하지 않음 |
| 글꼴 | 시스템 sans-serif, 한국어는 맑은 고딕 등 시스템 대체 글꼴. 외부 폰트 다운로드 없음 |
| 크기 | PC 화면 제목 30px, 소식 제목 17px, 요약 13px, 보조 정보 11–12px |
| 목록 간격 | 소식 상하 20px, 제목과 요약은 가까이 배치 |
| 화면 폭 | 최대 1200px, PC 사이드바 196px, 600px 이하 하단 메뉴 |

## 조작과 접근성

| 조작 | 적용 |
|---|---|
| 유형 필터·화면 전환 | 반복 사용하므로 애니메이션 없이 즉시 전환. 선택 상태와 키보드 포커스 표시 |
| 읽음·북마크 | 명시적 버튼과 상태 텍스트, 처리 결과 알림 |
| 모바일 메뉴·주요 카드 동작 | 44px 이상 터치 영역, 하단 안전 영역 고려 |

| 설정 | 입력에 레이블, 저장 버튼은 흰 글자와 녹색 배경 |

## 검증과 범위

Windows Edge에서 PC·모바일 캡처를 확인했습니다. 320·360·768·1100px에서 주요 화면 가로 넘침, 360px 하단 메뉴 위치, 기존 필터·회차·읽음·북마크·재생성 동작 검사를 통과했습니다. 실제 iOS Safari와 실기기 사용성은 아직 검증하지 않았습니다. 현재 결과물은 목업이며 수집·서버·영속 저장 구현은 포함하지 않습니다.
